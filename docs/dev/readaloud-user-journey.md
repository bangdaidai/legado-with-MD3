# 朗读功能：从用户角度的一份说明书

这份只讲**你在屏幕上看到什么、点了会发生什么**。工程侧的表结构、文件行号、施工顺序都在
`readaloud-cast-consolidation.md`，两份互不重复；文末有对照表，标出这里的每条说法出自那份的哪一节。

界面上的词全部照抄当前版本，不是我以为的名字。

## 一、能碰到朗读的地方，一共 9 处

| 在哪 | 进去能看到什么 |
|---|---|
| 阅读器菜单（点正文出菜单） | 朗读、多角色朗读、多角色分配、人物配音、AI 识别背景音乐、听书下载 |
| 朗读设置页 | 两个 Tab：「常规」和「引擎与音色」 |
| 朗读引擎与音色页 | 音色列表 + 引擎列表，分「云 TTS／HTTP 协议 TTS／系统 TTS」三组；点开一个音色的编辑弹窗里有「分类标注」三栏（性别／年龄段／风格标签） |
| 人物配音页 | 旁白一行 + 「人物」分组，每行是「角色名 · 声音 · 自动选音/你选的 · N 章 N 句」；AI 认出但还没转正的角色挂在同一组里，行右侧「更多」菜单有「转正」 |
| 分镜结果页 | 一章一段一段列出来，每行标着旁白／心声／对白／未知，灰行写说话人·情绪·音色；行右上角两颗小圆钮：锁定这一段、试听这一句 |
| 角色胶囊面板（正文里点角色标记） | 「分配角色」：角色名、角色声音池、音色、变声器（只这一句）。选完**当场**视为这一句定稿——分镜结果页那一行立刻跟着变，重跑本章分析不再改它 |
| 角色声音池页 / 背景音乐池页 | 池的分组、导入导出、新建；新建/编辑池的弹窗另有「性别 / 年龄段」两栏（只给自动选音用） |
| 朗读缓存页 | 缓存文件、操作日志、清除所有 |
| 知识页 | 整本人物识别（它只建人物档案，不管每句话归谁） |

**这里已经有两处重复**：「多角色朗读」「显示角色」这两个开关，阅读器菜单里有一份、朗读设置页里有一份，
是同一个东西的两个入口。

## 二、朗读设置页里每一项，实际管什么

### Tab「常规」（13 项）

默认朗读界面（经典朗读控制／听书播放器）、播放器背景（纯色／模糊／流光／透明）、显示朗读胶囊、
自动收缩胶囊（开着胶囊才有）、忽略音频焦点、来电期间暂停朗读、朗读服务唤醒锁、退出阅读时继续朗读、
媒体按钮·上一首|下一首、安卓媒体控制、使用媒体通道、流式播放音频、重置朗读胶囊位置。

这一 Tab 全部是"播放行为"，跟谁说话、用什么声音无关，不需要动。

### Tab「引擎与音色」（原有那些项，2026-10-21 起插了四个小标题：〔声音〕〔多角色朗读（AI）〕〔切分与节奏〕〔缓存〕）

| 界面上的词 | 实际管什么 |
|---|---|
| 朗读引擎与音色 | 跳进去选引擎和音色 |
| 朗读缓存 | 跳进去看/清缓存文件 |
| 人物与角色配音 | 跳进去给旁白和每个角色定声音 |
| **章节分片方式** | 其实是**要不要用 AI 判说话人**：规则分片／规则分片与 AI 补全／AI 理解分片 |
| 分镜结果 | 跳进去看这一章每句判成什么 |
| **分析推理级别** | AI 想多久：关闭／自动／轻度／中／高／极高／最高，默认**关闭** |
| **内容划分方式** | 其实是**一句念多大**：默认／整段／整页／按符号（选"按符号"才出现标点多选） |
| 多角色朗读 | 总闸：开着才换声音、才会跑 AI 分析 |
| 显示角色 | 正文里显不显示角色标记和胶囊、能不能点着分 |
| **归因口径**（2026-10-21 新增） | AI 判不准一句话归谁时怎么办：必答（默认，每条都给一个人）／宁缺毋滥（拿不准留空用默认音） |
| **顺带往后分析几章**（2026-10-21 新增） | 播当前章时额外往后分析几章（默认 0）。它**不改变这一章怎么判**，所以换它不会让已分析的章作废 |
| 背景音乐分配 | 要不要给章节配场景音乐 |
| 角色声音池 / 背景音乐池 / 系统 TTS 设置 | 三个跳转 |
| 听书预载数量(0-100) | **名不符实**：它其实是"往后预下载多少章的正文"，和「下载与缓存」页里那个数是同一个 |
| 预合成线程数(1-8) | 后台同时合成几章的音频 |
| 段落间隔(毫秒)(0-5000) | 段与段之间停多久 |
| 音频缓存保留时间(分钟)(0-10080) | 音频存多久 |
| 清理缓存 | 一键清 |

**这一页上跟"谁说话"有关的只有五项**：章节分片方式、分析推理级别、归因口径、顺带往后分析几章、多角色朗读。
其余是切分、节奏、缓存。另外三处需要留意：

- 「章节分片方式」和「内容划分方式」两个名字都像"切分"，一个管 AI、一个管句长，用户必然会挑错。
- 「听书预载数量」管的是正文预下载；**真正在后台预取音频的那个数，这页没有入口**。
- 推理强度**只有这一份**（7 档，默认关闭，2026-10-21 合一）：以前「AI 分配角色」弹窗里还有一份 5 档、
  各存各的，那个弹窗已经退役；现在朗读界面里只回显，改只能在这页改。

## 三、点了「朗读」之后，按真实顺序发生什么

这一步是整份说明里最重要的，因为**它是等完才出声的，不是边读边算**。

1. 服务开始准备这一章：取正文、按你选的「内容划分方式」切成段。
2. **先出结果才出声。** 如果这一章从没分析过：规则分段 → 若「章节分片方式」带 AI，就等 AI 回完
   （推理级别越高等越久）→ 给没声音的角色自动补一个音色 → 建好整章的播放队列 → 念出第一句。
   只要这一章之前有过结果（不管当时是什么设置、什么模型），就直接照用那一版，几乎立刻出声、
   不再花一次钱；**改了设置也不会让这一章重跑**（2026-10-21 D9，见第五节）。
3. 中途你快速翻页或换章，上一轮算到一半的分析会被掐掉。这**不算失败**，不弹提示——以前会误弹
   "AI 未启用/失败"，现在已经排掉了。
4. 于是你听到的：叙述句用旁白声（没专门设过就用你选的默认旁白／引擎默认音）；对白句如果那个角色有声音，
   就换成他的声音。
5. 如果 AI 这一章认出了新的人：自动建一张"临时角色"卡，并按声音池自动给他配一个声音。
   自动配的那一个**在配音页行上标着「自动选音」**，你手动换过的标「你选的」（2026-10-21 起分得出来）。
   自动选音走的是同一条打分链，不再掷随机：先挑被用得少的，其次按年龄段、风格标签、引擎、名字排。
   同一个池里第一个角色占走 A，第二个看到 A 用过了就排到 B。"这个音色是男是女、多大"按
   **你标的 > 池的分类 > 引擎声明 > 名字猜** 四级回落（2026-10-21）。
   以前"你想给这个临时角色手动换个声音，会顺手把整本书的旁白改掉"那条 bug 已修（2026-10-20）：
   现在这一行保存的音色写的是这个临时角色自己，旁白不动。
6. 后台还会"预合成"接下来几章，同一条分析链再跑一遍（「预合成线程数」管它）。
7. 出了问题你看到什么：没配 AI 模型、或这一章 AI 失败，会回落成"按规则念"。这两条**只在朗读过程中以
   提示出现**，同时都写进日志（书源编辑页溢出菜单→日志能看全文）。**第三种情况以前什么都没有**：
   同一本书失败之后的 10 分钟内，AI 请求整个跳过、不提示，你只会觉得"突然全变回一个音"。
   现在这一步也会说话——一轮冷却里第一次跳过弹提示，每次跳过都往日志写一行
   "第 N 章跳过 AI，按规则读——冷却还剩 X 秒"。

### 还有一个容易误解的点：改完能不能马上听到

- **在配音页改角色的声音** → 会整套重启朗读管线（有一下停顿、从当前位置重放），本章立刻变。
- **在正文点胶囊改某一句的归属** → 胶囊上那行字立刻变，**分镜结果页那一行也立刻变**（2026-10-21 起当场
  写进库里那一句的分段），但**正在播的这一章不会变**：整章的声音安排是准备时一次性建好排进队列的，
  改归属不重建队列。要等本章重新准备（换章、退出重进、手动重新朗读）才听得出来。
- **改过的这一句当场就是"定稿"**（2026-10-21）：点「确认／新建」那一刻，归属写进库里那一句的分段并
   锁住，之后**重跑本章分析不再改动它**——不是一行记录等着下次准备时才生效。顶掉过别人结论的会在日志里
   留一行"定稿: 第 N 章第 x 句改给「…」，写进 y 段并锁住"。只有两种情况这一步会空着不写（日志里会说明）：
   这一章还没分析过，或者**正文本身换过了**（重新下载这一章、改替换规则、开关「显示角色」都会让那几段的
   坐标对不上现在的字）；这两种都由出计划时那一次兜底补上。改划分方式／模型／提示词**不在这两种里**。
   按句定稿要把「内容划分方式」放到句级——选「整段」时那一整段一起成为定稿，这是划分方式本身的粒度，
   不是这里额外造成的。
- **点胶囊面板里那颗「取消分配」= 当场放开那句的定稿并回落旁白**（2026-10-21）：不是只删一行记录就完事，
   那句会立刻回到"没人认领"的状态。目录长按菜单的「删除分配」同理，一次放开整章。
   想听 AI 原来的判断，取消之后重跑本章分析。
- **改「内容划分方式」／「章节分片方式」／模型／提示词／归因口径** → **已经做好的分镜一个都不动**（2026-10-21）：
   不重切、不重跑 AI、不作废、也不会有任何"这份没用上"的提醒。这几个设置从此只管**还没跑过的章**——
   往后新遇到的章按新口径来，已经念过的章保持当时那一版。想按新口径重判，用分镜结果页顶栏的「重新分析」；
   想按新的句长粒度重新切，也是那里（或先删掉这一章的分镜结果再听）。
   朗读会因此重启一次（划分方式／分片方式／归因口径这三项会），但那只是为了让**后面**还没跑过的章
   按新设置来跑，不是在重做前面的章。

## 四、一本书从头到尾，最省事的走法

1. **引擎与音色页**：选引擎 → 在音色列表里长按一个音色，行上标出「默认旁白」＝设为全书叙述声 →
   （可选）把常用的一批音色归进一个声音池。
2. **朗读设置 → 引擎与音色 Tab**：开「多角色朗读」→「章节分片方式」选"规则分片与 AI 补全"→
   「分析推理级别」按你的模型定（默认关闭最省；会只出答案不出思考的模型才需要开）。
3. **人物配音页**：先给"旁白"定一个本书旁白声；重要角色**先绑好音色**再去听——
   绑过的角色 AI 不会替你改声线，也省掉一次自动补音。
4. **点朗读**（第一遍会等）。
5. **听感不对的那句**：正文点那颗胶囊 → 面板里改角色名（选已有的／新建）、声音池、音色、这一句的变声器，
   点「确认」；不想让他说了就点「取消分配」（那句回到旁白）。改完界面上立刻生效，分镜结果页那一行也是
   那一个角色（当场算定稿，重跑本章分析不会再动它）；**耳朵要等本章重新准备才听得出来**（见上）。
   新建时如果这个名字已经有一个人，会当场说"这个人已经建过了（同名只留一个角色），可直接点「确认」分配"，
   不会再多出一个同名的他。
6. **想看整章判成什么样**：分镜结果页。每行标着说话人、情绪、音色，详情里会写这条结论是
   "规则判定／本地推断／AI 判定／手动指定／兜底推断"哪一种。行右上角那颗锁是**锁定这一段**：
   锁上之后重新分析不会再改这一句的说话人（正文胶囊改的是"这一句算谁的"，锁的是"这个结论别动"，
   两个动作不同层）。要重判这一章，用顶栏的「重新分析」。
   看**别的章**也行：这一页读的就是库里那一份分段，而正文胶囊改的也正是那一份，所以你在正文改过的句子，
   这一页显示的就是改后的归属（定稿直接落在分段上，不再靠页面当场套一层覆盖）。改完归属**这一页立刻可见**，
   但耳朵听到的还是这一次准备时建好的那份队列——两侧共用一条计划链，差别只在队列不重建。
7. **嫌花钱**：关掉「多角色朗读」——整本回到一个旁白声，连分析都不跑
   （例外：你设过正则角色规则的话，那条还会生效）。
8. **怀疑没生效**：去日志，不用靠猜。

## 五、"整本一个音 / AI 像没起作用"的六个真实原因

按现在的实现，症状一样，原因不同。原本只有前两种会给你提示，后面几种全靠猜；
现在这六种各有各的说法（第 4 条那本"另一本账"已于 2026-10-21 退役，留在这里是给你对照旧记录用）：

1. 「多角色朗读」关着（或「章节分片方式」是纯规则）→ 根本不会问 AI。
2. 没配 AI 模型 / 这一章 AI 请求失败 → 回落成规则结果，播放中有提示。配了模型才能进
   「AI 识别背景音乐」那道门，没配的话点入口就会当场说清楚，不会让你选完范围才报错。
3. 同一本书 10 分钟冷却内 → 这一章跳过 AI 按规则读。**冷却第一次命中会弹一句"还剩几秒"**，
   同一轮冷却里后面的章节只进日志——每章弹一次会被当成坏了。
4. 以前还有第四本账：「AI 分配角色」弹窗自己认一遍 → 它认不到的句子会被**直接判成旁白**，
   把 AI 分析链已经认出的结论擦掉。这就是"日志里明明有记录、耳朵里却没人"的主因。
   **这条链连同它的判断规则、分配要求预设、临时要求、本书角色记忆编辑器已于 2026-10-21 退役**：
   逐句归属只剩朗读链路一个产出方，手工改归属走正文胶囊和配音页那两个入口。
   同一批还撤掉了播出前那层"按正文标记现场认领说话人"的覆盖（2026-10-21）——那一层认领不到的句子
   同样判成旁白，等于播放队列自己又判了一遍归属。现在它只剩两件事：正则角色顶音色／放音效、
   那一句自己的变声器。**"从没分配过的句子被整句抹成旁白"这一路彻底没有了**，
   分镜页那一行也和实际发声的单元一一对应（只有真设了句级变声器的那几句才被单独切开）。
5. 角色的音色被停用或删除了 → 那句退回旁白音（日志里会写一句）。
6. 改角色档案（转正、改名、换池、哪怕只在详情页动了头像）**不再让整本书重新分析**——
   名册已经从分析缓存的键里移出去。代价是有意的：旧章不会因为档案变化自动变得更准，
   要按新名册重判就显式点「重新分析」。

### 以前那枚「按以前的设置分析，听书没用上」，已经删掉了（2026-10-21）

它长在**章节列表的每一行**上，意思是"这一章留着的分析记录跟现在的设置对不上号，别当准"；点开那一章，
配置卡里还给一段完整解释。现在徽标和那段说明都不在了，因为这句话本身不成立。

以前那把尺子量的是"这一章有没有一条**版本号等于当前设置**的记录"，而那个版本号把两件事捆在一起：
**一句念多大**（内容划分方式）和**这句话归谁**（AI 分析）。所以你把划分方式从"整段"改成"按符号"，
说话人的结论一个字都没变，也会被当成"没分析过"——旧结果作废、重新切、重新烧一次 AI。同理还有换模型、
换分析模式、改提示词。

现在只看两件事：**这一章有没有结果**，以及**那几段还落在现在这份正文上吗**。前者决定要不要跑，
后者只在正文真的换了时才会拦（重新下载这一章、改替换规则、开关「显示角色」会把坐标挪走），
这时才会重新分析——那确实是该重跑的情形。

代价是明确的一条，写在前面免得你以为坏了：**换了「内容划分方式」之后，已经读过的章还是老切法**，
一句念多长跟以前一样，只有往后新跑的章才用新粒度。这是"不让已有结果作废"的另一面。
要立刻按新粒度来就在分镜结果页点「重新分析」（或删掉这一章的分镜结果再听）。

点进一章仍然不会自动重跑，只读库里那一份；改归属要立刻在页面上看见就走正文胶囊（当场定稿）。

还有一条兜底（当场写定稿和出计划时补写，两边同一把尺子）：把正文里的"第几句"对到库里那一段之前，
先确认那几段还量得到现在这份正文。对不上就宁可不写定稿，也不按错位置把归属安到别人头上，
日志里会写一行说明原因。**只有正文换过才会对不上，改划分方式不会。**
**关掉「显示角色」就等于没有按句的分配可读**——正文里没有标记，那一句一句的归属自然量不出来，
但整章的音色照旧（音色来自分析链那一份，不依赖标记）。
正则命中那一句优先级仍最高：它盖掉的是"这一句原本分好的角色"，正则角色那页的说明里已写明。
