# 朗读功能：从用户角度的一份说明书

这份只讲**你在屏幕上看到什么、点了会发生什么**。工程侧的表结构、文件行号、施工顺序都在
`readaloud-cast-consolidation.md`，两份互不重复；文末有对照表，标出这里的每条说法出自那份的哪一节。

界面上的词全部照抄当前版本，不是我以为的名字。

## 一、能碰到朗读的地方，一共 9 处

| 在哪 | 进去能看到什么 |
|---|---|
| 阅读器菜单（点正文出菜单） | 朗读、多角色朗读、多角色分配、人物配音、AI 分配角色、听书下载 |
| 朗读设置页 | 两个 Tab：「常规」和「引擎与音色」 |
| 朗读引擎与音色页 | 音色列表 + 引擎列表，分「云 TTS／HTTP 协议 TTS／系统 TTS」三组 |
| 人物配音页 | 旁白一行 + 「人物」分组，每行是「角色名 · 声音 · N 章 N 句」；AI 认出但还没转正的角色挂在同一组里，行右侧「更多」菜单有「转正」 |
| 分镜结果页 | 一章一段一段列出来，每行标着旁白／心声／对白／未知，灰行写说话人·情绪·音色；行右上角两颗小圆钮：锁定这一段、试听这一句 |
| 角色胶囊面板（正文里点角色标记） | 「分配角色」：角色名、角色声音池、音色、变声器（只这一句） |
| 角色声音池页 / 背景音乐池页 | 池的分组、导入导出、新建 |
| 朗读缓存页 | 缓存文件、操作日志、清除所有 |
| 知识页 | 整本人物识别（它只建人物档案，不管每句话归谁） |

**这里已经有两处重复**：「多角色朗读」「多角色分配」这两个开关，阅读器菜单里有一份、朗读设置页里有一份，
是同一个东西的两个入口。

## 二、朗读设置页里每一项，实际管什么

### Tab「常规」（13 项）

默认朗读界面（经典朗读控制／听书播放器）、播放器背景（纯色／模糊／流光／透明）、显示朗读胶囊、
自动收缩胶囊（开着胶囊才有）、忽略音频焦点、来电期间暂停朗读、朗读服务唤醒锁、退出阅读时继续朗读、
媒体按钮·上一首|下一首、安卓媒体控制、使用媒体通道、流式播放音频、重置朗读胶囊位置。

这一 Tab 全部是"播放行为"，跟谁说话、用什么声音无关，不需要动。

### Tab「引擎与音色」（18 项，四类东西穿插着排）

| 界面上的词 | 实际管什么 |
|---|---|
| 朗读引擎与音色 | 跳进去选引擎和音色 |
| 朗读缓存 | 跳进去看/清缓存文件 |
| 人物与角色配音 | 跳进去给旁白和每个角色定声音 |
| **章节分片方式** | 其实是**要不要用 AI 判说话人**：规则分片／规则分片与 AI 补全／AI 理解分片 |
| 分镜结果 | 跳进去看这一章每句判成什么 |
| **分析推理级别** | AI 想多久：关闭／自动／轻度／中／高／极高／最高，默认**关闭** |
| **内容划分方式** | 其实是**一句念多大**：默认／整段／整页／按符号（选"按符号"才出现标点多选） |
| 多角色朗读 | 总闸：开着才换声音、才会跑 AI 分析 |
| 多角色分配 | 正文里显不显示角色标记和胶囊、能不能点着分 |
| 背景音乐分配 | 要不要给章节配场景音乐 |
| 角色声音池 / 背景音乐池 / 系统 TTS 设置 | 三个跳转 |
| 听书预载数量(0-100) | **名不符实**：它其实是"往后预下载多少章的正文"，和「下载与缓存」页里那个数是同一个 |
| 预合成线程数(1-8) | 后台同时合成几章的音频 |
| 段落间隔(毫秒)(0-5000) | 段与段之间停多久 |
| 音频缓存保留时间(分钟)(0-10080) | 音频存多久 |
| 清理缓存 | 一键清 |

**这一页上跟"谁说话"有关的只有三项**：章节分片方式、分析推理级别、多角色朗读。其余是切分、节奏、缓存。
另外三处需要留意：

- 「章节分片方式」和「内容划分方式」两个名字都像"切分"，一个管 AI、一个管句长，用户必然会挑错。
- 「听书预载数量」管的是正文预下载；**真正在后台预取音频的那个数，这页没有入口**。
- 推理强度在这页有一份（7 档，默认关闭），在「AI 分配角色」弹窗里还有一份（5 档，默认跟随模型），
  两处存的是不同的地方，各改各的。

## 三、点了「朗读」之后，按真实顺序发生什么

这一步是整份说明里最重要的，因为**它是等完才出声的，不是边读边算**。

1. 服务开始准备这一章：取正文、按你选的「内容划分方式」切成段。
2. **先出结果才出声。** 如果这一章从没分析过：规则分段 → 若「章节分片方式」带 AI，就等 AI 回完
   （推理级别越高等越久）→ 给没声音的角色自动补一个音色 → 建好整章的播放队列 → 念出第一句。
   命中缓存（这章之前分析过、文本和模型都没变）就几乎立刻出声，也不会再花一次钱。
3. 中途你快速翻页或换章，上一轮算到一半的分析会被掐掉。这**不算失败**，不弹提示——以前会误弹
   "AI 未启用/失败"，现在已经排掉了。
4. 于是你听到的：叙述句用旁白声（没专门设过就用你选的默认旁白／引擎默认音）；对白句如果那个角色有声音，
   就换成他的声音。
5. 如果 AI 这一章认出了新的人：自动建一张"临时角色"卡，并按声音池自动给他配一个声音。
   剩下的坑只有一个：**自动配的声音在界面上没标"是自动的"**，看不出是谁定的（排在选音合一那轮）。
   以前"你想给这个临时角色手动换个声音，会顺手把整本书的旁白改掉"那条 bug 已修（2026-10-20）：
   现在这一行保存的音色写的是这个临时角色自己，旁白不动。
6. 后台还会"预合成"接下来几章，同一条分析链再跑一遍（「预合成线程数」管它）。
7. 出了问题你看到什么：没配 AI 模型、或这一章 AI 失败，会回落成"按规则念"。这两条**只在朗读过程中以
   提示出现**，同时都写进日志（书源编辑页溢出菜单→日志能看全文）。**第三种情况以前什么都没有**：
   同一本书失败之后的 10 分钟内，AI 请求整个跳过、不提示，你只会觉得"突然全变回一个音"。
   现在这一步也会说话——一轮冷却里第一次跳过弹提示，每次跳过都往日志写一行
   "第 N 章跳过 AI，按规则读——冷却还剩 X 秒"。

### 还有一个容易误解的点：改完能不能马上听到

- **在配音页改角色的声音** → 会整套重启朗读管线（有一下停顿、从当前位置重放），本章立刻变。
- **在正文点胶囊改某一句的归属** → 胶囊上那行字立刻变，但**正在播的这一章不会变**：整章的声音安排是
  准备时一次性建好排进队列的，改归属不重建队列。要等本章重新准备（换章、退出重进、手动重新朗读）才听得出来。

## 四、一本书从头到尾，最省事的走法

1. **引擎与音色页**：选引擎 → 在音色列表里长按一个音色，行上标出「默认旁白」＝设为全书叙述声 →
   （可选）把常用的一批音色归进一个声音池。
2. **朗读设置 → 引擎与音色 Tab**：开「多角色朗读」→「章节分片方式」选"规则分片与 AI 补全"→
   「分析推理级别」按你的模型定（默认关闭最省；会只出答案不出思考的模型才需要开）。
3. **人物配音页**：先给"旁白"定一个本书旁白声；重要角色**先绑好音色**再去听——
   绑过的角色 AI 不会替你改声线，也省掉一次自动补音。
4. **点朗读**（第一遍会等）。
5. **听感不对的那句**：正文点那颗胶囊 → 选已有角色／新建／归为旁白。改完界面上立刻生效，
   本章要等重新准备才听得出来（见上）。
6. **想看整章判成什么样**：分镜结果页。每行标着说话人、情绪、音色，详情里会写这条结论是
   "规则判定／本地推断／AI 判定／手动指定／兜底推断"哪一种。行右上角那颗锁是**锁定这一段**：
   锁上之后重新分析不会再改这一句的说话人（正文胶囊改的是"这一句算谁的"，锁的是"这个结论别动"，
   两个动作不同层）。要重判这一章，用顶栏的「重新分析」。
   看**别的章**也行：那三章（上一章／当前章／下一章）里正文还在阅读器手上的，分镜页会把你在正文
   改过的归属一起算进来显示；翻远了就只显示库里那份原始结论。
7. **嫌花钱**：关掉「多角色朗读」——整本回到一个旁白声，连分析都不跑
   （例外：你设过正则角色规则的话，那条还会生效）。
8. **怀疑没生效**：去日志，不用靠猜。

## 五、"整本一个音 / AI 像没起作用"的六个真实原因

按现在的实现，症状一样，原因不同。原本只有前两种会给你提示，后面几种全靠猜；
现在这六种各有各的说法：

1. 「按角色分声朗读」关着（或「章节分片方式」是纯规则）→ 根本不会问 AI。
2. 没配 AI 模型 / 这一章 AI 请求失败 → 回落成规则结果，播放中有提示。配了模型才能进
   「AI 分配角色」那道门，没配的话点入口就会当场说清楚，不会让你选完范围才报错。
3. 同一本书 10 分钟冷却内 → 这一章跳过 AI 按规则读。**冷却第一次命中会弹一句"还剩几秒"**，
   同一轮冷却里后面的章节只进日志——每章弹一次会被当成坏了。
4. 你用的是「AI 分配角色」弹窗那套（另一本账）→ 它认不到的句子会被**直接判成旁白**，
   把 AI 分析链已经认出的结论擦掉。这就是"日志里明明有记录、耳朵里却没人"的主因。
5. 角色的音色被停用或删除了 → 那句退回旁白音（日志里会写一句）。
6. 改角色档案（转正、改名、换池、哪怕只在详情页动了头像）**不再让整本书重新分析**——
   名册已经从分析缓存的键里移出去。代价是有意的：旧章不会因为档案变化自动变得更准，
   要按新名册重判就显式点「重新分析」。

### 顺带说清分镜页那句「按以前的设置分析，听书没用上」

它长在**章节列表的每一行**上，不是场景行；点开这一章，配置卡里会给完整解释和该点的按钮。
意思是：这一章留着的分析记录跟现在的设置对不上号，所以页面上显示的角色和音色不能当准。
会让它对不上的只有四个动作——换 AI 模型、换「章节分片方式」、换「内容划分方式」、改提示词。
**改角色档案不在里面了**（它曾经在，而且是"整本书齐刷刷挂徽标"的主要来源）。

两条要知道的：**点进这一章不会自动重跑**（只读库里那一份，当前章有结果时也只重算音色），
顶栏「重新分析」才是重跑这一章的入口；判据现在是"这一章有没有版本号等于当前设置的记录"，
以前那句"最后一次写库的是哪份"会带来假阳性——切回旧设置重读过仍挂着徽标，因为命中缓存不改写时间，
这条已经修掉。

还有一条兜底：分镜页要把你在正文改过的归属套到库里的分段上，得先确认手上这份正文和分析当时
是**同一份**（对一次内容哈希）。挂徽标的那种旧记录没有可比基准，直接不套；改过「正文显示角色名」
这类会影响正文标记的设置后也可能对不上，此时宁可只显示库里那份原始结论，也不按错位置把归属安到
别人头上。日志里会写一句"跳过分配表覆盖"和原因。

## 六、按目标形态走，同样的操作有哪几处不一样

| 你会感觉到的差别 | 现在 | 目标 |
|---|---|---|
| 设置页里 AI 相关的项 | 和缓存、节奏穿插在一列 18 项里 | 插四个小标题：〔声音〕〔多角色朗读（AI）〕〔切分与节奏〕〔缓存〕，不新增页面 |
| 两个都像"分片"的下拉 | 章节分片方式 / 内容划分方式 | 一个管"要不要用 AI 判说话人"，一个管"一句念多大"，名字分开写清 |
| 推理强度 | **已合一**（2026-10-20）：只留朗读设置那一份 7 档，「AI 分配角色」弹窗里改成只回显、不能再各改各的 | 保持一份 |
| 「AI 分配角色」弹窗 | 第三个执行入口，还会覆盖 AI 分析链的结论 | 退役；它的判断规则并进唯一一次分析，范围变成一个档位「听书时顺带往后分析几章」 |
| 改一句归属 | 本章听不到（要等重新准备）。分镜页**不再只跟着当前章**（2026-10-20）：正文还在阅读器手上的章都把改动算进来显示，行上另有「锁定这一段」把结论钉住，重跑跳过它 | 归属改动还能同时写成那一句的定稿记录（这一步还没做：分配表按"第几句"锚定、分段按正文位置锚定，中间缺一条可靠的桥） |
| 给临时角色选声音 | **已修**（2026-10-20）：只改他，旁白不动。**转正入口也补上了**（同日）：这一行右侧的「更多」菜单里有「转正」，转正后换头像、设气泡、进人物详情才都开放 | 同 |
| 自动配的声音 | 和你选的分不出来 | 行上标「自动选音」／「你选的」 |
| 改角色档案 | **已不再引发整本书重跑**（2026-10-20：角色库从分析缓存键里移出）。代价是一次性的——键变了，已分析过的章下次真正听到时各重跑一次 AI | 要更准就用「重新分析本章」显式做 |
| 一个人物 | 可能两条记录、两个声音 | 一人一行、一个声音 |
| 失败 / 冷却 / 纯规则 | **三种都会说话**（2026-10-20）：冷却跳过写日志、一轮冷却第一次弹提示；分镜页自己订了一份回落提示，没在播放也看得见 | 同 |
