## 本分支改动（2026/07/24 起）

以下是本分支相对上游 legado-with-MD3 的全部改动，按功能模块归纳。

### 标签体系与书架

* 全新标签系统：书架、书籍详情、阅读记忆三处共用同一份标签数据
* 标签分组支持拖拽排序，书架标签按分组顺序展示
* 标签边框开关，标签色描边与主题边框适配，书籍详情页同步
* 排除标签管理页，隐藏零计数标签，删除书籍时级联清理标签关联
* 书架票据样式卡片，虚线支持段线/点线切换，多齿孔注册机制
* 连载/完本分组改为按状态标签判定，新增「坑书」「已读」分组
* 未读徽章改用高对比配色，阅读状态词统一为未读/在读/已读
* 换源按「替换书籍」处理，新增同名同作者同形态开关（设置在 高级-阅读）
* 统一下架书删除确认对话框，修复下架书残留

### 阅读记忆与阅读记录

* 阅读记忆新增独立标签字段，移出书架后标签完整保留
* 详情页阅读数据改为 2×2 网格卡片，点封面直接进阅读器
* 阅读记录按书籍类型统计，类型筛选改为选项卡片，字数统一万字单位
* 热力图改版：默认聚焦当前日期、选中日期水平居中、支持滚动定位
* 新增按年阅读柱状图
* 阅读会话按实际阅读进度累计字数，新增挂机检测，60 秒无操作自动切段
* 相邻会话（间隔 ≤1 分钟）写库即合并，展示层再合并同书相邻会话，删除按区间清空
* 时间线冗余存储章节名，修复视频集数丢失；长章节名不再挤压时长
* 列表简介/书评跟随书架的显示设置，改用 GlassCard 包裹
* 书籍卡片支持单行滚动标签，作者详情页复用

### 分享卡片（原「藏书票」）

* 更名为分享卡片，新增调色板按钮换色、亮/暗一键切换、长按保存到相册
* 模板纳入备份与恢复，新增粉色内置模板
* 阅读页选中文字可直接生成卡片，不必先存笔记
* 预览渲染多轮重做：实时 WebView → 离屏出图 + 热 WebView + JS 桥，两阶段就绪机制
* 出图更快、开门零转圈，消除高度抖动、二段跳、切色切模板卡顿
* 封面预取与独立缓存、在途请求合流，先过 AnalyzeUrl 并校验状态码
* 模板变量全部 HTML 转义，出图高度设上限防坏模板 OOM

### 划线、笔记与高亮

* 笔记页面重构：书签与笔记拆为独立功能，笔记编辑统一化
* 划线默认样式面板 + 实时预览，新增荧光笔效果，粗细/偏移改为全局设置并对已有标记生效
* 下划线支持端点圆角、羽化、虚线段长与间隔自定义，文字下层下划线真正生效
* 高亮规则支持角色分级主角高亮，人物档案纳入备份
* 简介角色提取规则可配置，支持配角与听书音色
* 高亮预览背景跟随应用排版；命中标签不再在下方重复
* 笔记与书评展示不再限制行数，换源时同步迁移书摘

### 听书与朗读

* 多角色朗读：音色路由、临时说话人、自动选音
* 音色列表支持试听，补性别/风格标签，朗读加「准备中」状态
* 新增分镜结果页，分镜按章展示，入口挪进朗读设置
* AI 说话人分析可关思考、失败进冷却，说话人规则补零主语承前与小句主语归属
* 删书时立刻清掉整本分镜，孤儿清理降为兜底
* 修复系统 TTS 语音 id 重复导致的崩溃，朗读设置弹窗切 tab 高度改为动画过渡
* 二级页面返回统一回到听书设置，不再越级退回阅读页

### 作者管理（新功能）

* 新增作者管理页：列表卡片、排序、索引分组、搜索
* 作者详情独立为导航路由，保留返回栈层级；新增阅读状态 tab
* 作者简介搬进数据库，支持自定义与 AI 生成，生成可接联网检索，写作要求开放到提示词设置
* 作者详情新增跨书源搜索「其他作品」，结果持久化缓存
* 关联书籍分区加状态筛选，书籍卡片简介/书评分开排版，书目按阅读进度倒序

### 书籍详情与关联书籍

* 关联书籍打通完整数据层（DAO / Repository / Gateway / 换源）
* 关联书籍长按预览可加书架，长按作者进作者页，换源后不再消失
* 详情头部展示字数标签，可在标签规则页切换为高亮标签，换源时保留
* 书源编辑菜单新增关联书籍规则帮助，并入通用源规则帮助
* 书籍编辑页移除自定义标签，统一在阅读记忆详情页编辑

### 首页与发现

* 浏览书源加分类或空态刷新时自动创建书源集合，选完分类直接弹模块命名
* 长按模块「更多」按钮打开编辑弹窗，编辑分类后立即重载
* 未选中的分类正确持久化，模块禁用时取消进行中的加载
* 发现页标签行改 compact 胶囊、去掉勾选图标、补顶部与底部留白

### 换源与书源兼容

* 换源支持按字数过滤、换源到本地文件，并保留简介与封面
* 换源后重建标签关联，清理新地址上的残留
* 封面换源恢复展示封面规则结果，规则支持返回多张封面
* 补齐 legado-E 书源依赖的 `chapter.putImgUrl` / `putLyric` / `java.openVideoPlayer`
* 补回内置浏览器的 `window.close()`、`java`、`cache` JS 桥
* 新增 Hutool DigestUtil 兼容类、AES 密钥长度归一、base64 容错解码

### AI 与规则

* AI 聊天支持人设切换，接入 Tavily 联网搜索并统一请求失败分类
* AI 读真实目录反推净化规则，目录规则预览页支持批量采用、脚本规则样本试跑、规则改动实时生效
* 目录标题的替换净化改为按书开关，与正文开关解耦，未设置时跟随全局默认
* AI 设置纳入备份与恢复

### 主题与界面

* 底栏自定义图标支持 SVG、大小可调、随选中态跟随主题着色
* 主题卡预览改用真实配色引擎；切回默认主题后标题栏不再残留自定义色
* 分割线颜色统一取主题「分割线颜色」设置
* 统一正文距标题栏、屏幕边距与卡片内边距规范
* 修复嵌套页面重复绘制背景图导致顶部被裁、书籍信息滑到状态栏下方
* 状态栏图标明暗按背景图与顶栏底色的合成结果判定

### 备份与恢复

* 兼容 r 项目的阅读记录备份，修复恢复后视图空白
* 恢复用兼容模型加 `@Keep`，修复 R8 混淆导致解析失败
* 扩大备份覆盖面，补齐遗漏的表与用户资源；恢复日志落地到文件

### 稳定性、数据库与构建

* 数据库版本策略对齐上游，本地新增列合入上游最新迁移
* 修复并发插入同名标签的唯一约束崩溃、标签归并残留、迁移缺列
* 修复书架状态派生、服务主线程阻塞、并发容器与取消处理问题
* 发布版本号带构建序号与 UTC 日期，versionCode 改 UTC 日期编码，修复跨工作流安装降级
* Release 随包上传 mapping.txt（gzip），本地字符串抽到 `strings_local.xml` 避免与上游冲突
* 引入配置架构护栏基线，逐步清理 UI 层 DAO 直连
